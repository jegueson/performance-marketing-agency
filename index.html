Performance Marketing Agency Hub

A self-hosted paid media dashboard. It pulls your Google Ads data into a local database and turns it into structured analysis prompts for AI assistants.

Runs locally Python standard library only No third-party servers

What it does

The application connects to the Google Ads API using your own credentials, stores a daily snapshot of campaign, keyword, search term and conversion data in a local SQLite database, and serves a dashboard from localhost on your own machine.

Seven specialist paid media agent personas are available. Selecting one assembles a prompt containing that persona plus the relevant slice of your account data, which you copy into an AI assistant of your choice.

Design principles

  • No installation. Uses only the Python standard library, so it runs on locked-down corporate machines where package installs are blocked.
  • No data leaves your machine. There is no backend service, no telemetry and no account. The database and credentials sit in the project folder.
  • Your own API access. Each user supplies their own Google Cloud OAuth client and Google Ads developer token.
