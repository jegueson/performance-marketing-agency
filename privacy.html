Privacy Policy

Performance Marketing Agency Hub · Effective 28 August 2026

Performance Marketing Agency Hub ("the application") is open-source software that runs entirely on the computer of the person who installs it. This policy explains what the application does with data, and what its developer does not do with it.

Summary: the developer of this application never receives your data. There is no server, no hosted service and no account. All data stays on your own machine.

1. Who operates this application

The application is distributed as source code. Each user installs and runs their own copy using their own Google Cloud project and their own Google Ads API credentials. The author of the software does not operate any service on your behalf and has no access to your installation.

2. What data the application accesses

When you authorise the application, it requests the https://www.googleapis.com/auth/adwords scope. This allows it to read reporting data from the Google Ads accounts you already have access to, including:

  • Account names, identifiers, currency and time zone settings
  • Campaign, ad group, ad, keyword and search term performance metrics
  • Conversion action configuration and conversion metrics

The application reads reporting data. It does not require or use any personal information about individual end users of your website, and Google Ads does not expose such information through these reports.

3. Where data is stored

All retrieved data is written to a SQLite database file inside the application folder on your computer (data/adshub.db). Your OAuth credentials and refresh token are stored in config.json in the same folder.

Neither file is transmitted anywhere. The application's only outbound network connections are to oauth2.googleapis.com and googleads.googleapis.com, both operated by Google.

4. What the application does not do

  • It does not send your data to the developer or any third party.
  • It does not include analytics, telemetry, tracking or crash reporting.
  • It does not sell, rent or share data with anyone.
  • It does not use Google user data to train, develop or improve any machine learning or artificial intelligence model.
  • It does not serve advertising.

5. Prompts and AI assistants

A core feature of the application is generating text prompts that combine an analyst persona with a summary of your advertising performance. These prompts are assembled locally and placed on your clipboard or saved as a file.

If you choose to paste a prompt into an external AI assistant, that data becomes subject to the privacy policy of the assistant you use. This action is always initiated by you. The application never sends prompts anywhere automatically.

6. Limited Use disclosure

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Data retention and deletion

Because all data is local, you control retention completely. The application keeps a rolling window of recent data, configurable in config.json, and deletes older records automatically on each sync.

To remove everything:

  • Delete the data folder to remove all cached advertising data.
  • Delete config.json to remove your stored credentials.
  • Revoke the application's access at myaccount.google.com/permissions.

8. Security

config.json contains a refresh token that grants access to your Google Ads data. It is excluded from version control and should not be shared or committed to a repository. Protect it as you would a password. Anyone with access to your computer's file system can read it.

9. Children

The application is a professional advertising tool and is not directed at, or intended for use by, anyone under the age of 16.

10. Changes to this policy

Any changes will be published on this page with a revised effective date. Because the application is versioned in a public repository, the history of this document is publicly auditable.
